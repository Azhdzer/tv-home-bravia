# Полная инструкция: Sony BRAVIA KD-55XF9005

Вы отключите на телевизоре рекламу и телеметрию и замените домашний экран на быстрый минималистичный лаунчер.
Понадобятся компьютер с Windows 10/11 и примерно 30 минут, из которых большая часть уходит на скачивание.

**Безопасно ли это?** Ничего не удаляется: пакеты только отключаются, прошивка не меняется, root не нужен. Перед
изменениями скрипты сохраняют копию состояния ТВ, а один скрипт возвращает всё обратно. Сброс ТВ к заводским
настройкам тоже полностью отменяет эти изменения.

**Насколько это проверено?** На настоящем телевизоре проект пока не запускался. Проверены установка инструментов и
сборка APK на Windows 10, логика всех скриптов (включая аварийные сценарии) на программной имитации ТВ и
совместимость кода с Android 7–9 компиляцией. Настройки взяты у владельцев ТВ на той же платформе (XBR-65X900F,
KD-55XF8096, KD-65A8F), где подход работает. Поэтому на шагах 3 и 9 проверьте результат: если ваш ТВ отличается,
скрипт предупредит об этом или откатит передачу кнопки Home.

Скачайте проект в папку, в пути к которой нет пробелов и кириллицы:

```powershell
git clone https://github.com/Azhdzer/tv-home-bravia.git D:\tv-home-bravia
```

Если Git не установлен, скачайте архив на [странице проекта](https://github.com/Azhdzer/tv-home-bravia) (**Code → Download ZIP**),
распакуйте его и один раз выполните в этой папке `Get-ChildItem -Recurse *.ps1 | Unblock-File`.

Все команды ниже выполняются в **PowerShell**, открытом **в папке проекта**:

```powershell
cd D:\tv-home-bravia
```

## Шаг 1. Подготовка телевизора

1. Включите ТВ и подключите его к той же сети, что и компьютер. Гостевая сеть Wi-Fi не подойдёт: она изолирует устройства друг от друга.
2. Откройте **Настройки** (шестерёнка) → **Настройки устройства** → **Об устройстве**. На некоторых прошивках путь такой: **Система** → **Об устройстве**.
3. Выберите строку **Сборка** и нажмите ОК **7 раз подряд**. Появится сообщение, что вы стали разработчиком.
4. Вернитесь на шаг назад: появился пункт **Для разработчиков**.
5. Откройте его и включите **Отладку по USB**. Если есть пункт **Отладка по сети** или **Отладка ADB**, включите и его.

Кабель USB не нужен: на этой платформе тот же переключатель открывает порт 5555 в сети. Названия пунктов на вашей
прошивке могут немного отличаться.

**Совет.** Закрепите за ТВ постоянный IP в настройках роутера (резервирование DHCP). Иначе после перезагрузки адрес
может смениться, и `tools\find-tv.ps1` придётся запускать снова.

## Шаг 2. Подготовка компьютера

Нужен Python 3.8 или новее. Проверьте:

```powershell
python --version
```

Если команда не сработала, установите Python с [python.org](https://www.python.org/downloads/) и при установке
отметьте **Add python.exe to PATH**.

Запустите настройку:

```powershell
.\setup.ps1
```

Скрипт скачает около **465 МБ**, займёт около 750 МБ на диске и ничего не поменяет в системе, всё ляжет в папку проекта:

| Что | Откуда | Размер |
|---|---|---:|
| Пакеты Python `adb-shell`, `rsa`, `cryptography` | pypi.org | несколько МБ |
| JDK 17 (Temurin) | adoptium.net | 182 МБ |
| Android command-line tools | dl.google.com | 156 МБ |
| Android SDK: платформа 28, build-tools 34 | dl.google.com | 128 МБ |

SDK Manager покажет **лицензионные соглашения Google**. Прочитайте их и ответьте `y`, если согласны: без этого
собрать лаунчер не получится.

Если нужно только отключить мусор, без нового домашнего экрана, хватит лёгкой настройки на несколько мегабайт:

```powershell
.\setup.ps1 -NoLauncher
```

## Шаг 3. Найти телевизор и подключиться

```powershell
tools\find-tv.ps1
```

Скрипт найдёт ТВ и запомнит его адрес. Если не нашёл, посмотрите IP в сетевых настройках ТВ и задайте его вручную:

```powershell
tools\find-tv.ps1 -Ip 192.168.1.50
```

**Если в сети есть другие телевизоры на Android**, убедитесь, что выбран именно Sony: следующая команда покажет
марку. Скрипты, которые что-то меняют, откажутся работать с ТВ другой марки.

Теперь подключитесь:

```powershell
tools\venv\Scripts\python.exe -I tools\tv.py --probe
```

**Смотрите на экран ТВ:** появится запрос **«Разрешить отладку по USB?»**. Отметьте **«Всегда разрешать с этого
компьютера»** и нажмите **ОК**. На ответ есть 2 минуты.

На телевизорах этой платформы вывод выглядит так:

```text
ro.product.manufacturer = Sony
ro.product.brand = Sony
ro.product.model = BRAVIA 4K GB ATV3
ro.product.device = BRAVIA_ATV3_4K
ro.build.version.release = 9
ro.build.version.sdk = 28
```

Номера KD-55XF9005 в этих данных не будет: система называет себя `BRAVIA 4K GB ATV3`, это нормально.

- **`ro.product.device` другой:** прошивка отличается от той, для которой составлен список. Лаунчер всё равно должен работать, но список на шаге 5 прочитайте особенно внимательно.
- **Android 7 или 8 вместо 9:** обновляться не обязательно, лаунчер поддерживает Android 7 и новее.

## Шаг 5. Решить, что отключать

Откройте [examples\sony-bravia-kd55xf9005\debloat.txt](examples/sony-bravia-kd55xf9005/debloat.txt).

**Отключается по умолчанию:** Samba TV (следит за тем, что на экране), реклама и витрины Sony, рекомендации,
автоустановка партнёрских приложений, настройка Alexa, демо-режим магазина, телеметрия, справка, Play Фильмы, Play Игры.

**Остаётся включённым, решаете вы.** Если функция не нужна, уберите `#` в начале соответствующей строки:

| Функция | Если отключить, то |
|---|---|
| Голосовой поиск, Ассистент | Кнопка микрофона перестанет работать |
| Chromecast | Нельзя будет транслировать с телефона |
| Зеркалирование экрана (Miracast) | Экран телефона не вывести на ТВ |
| Приложение-пульт на телефоне | Телефон перестанет работать пультом. **Может пропасть и микрофон Bluetooth-пульта** |
| DLNA | Не будет воспроизведения с компьютера или телефона по сети |
| Плееры USB | Файлы с флешки будет нечем открыть |
| HbbTV | Перестанет работать «красная кнопка» в цифровом эфире |
| Netflix, Prime Video и т. п. | Приложение исчезнет, кнопка Netflix на пульте перестанет работать |

**Никогда не отключайте** `com.sony.dtv.tvx` и `com.sony.dtv.tvinput.*` (ТВ и HDMI), `braviasync*` (управление по HDMI),
`com.sony.dtv.b2b.hotelmode` (на других моделях Sony это ломало Настройки), `com.sony.dtv.scrums.action` (Action Menu),
`com.mediatek.*` (работа с чипом), `com.android.vending`, `com.google.android.gms`. Скрипт откажется их отключать, даже
если они окажутся в списке.

## Шаг 6. Отключить мусор

Посмотрите, что будет сделано. На ТВ при этом ничего не отправляется:

```powershell
tools\disable.ps1 examples\sony-bravia-kd55xf9005\debloat.txt -DryRun
```

Примените:

```powershell
tools\disable.ps1 examples\sony-bravia-kd55xf9005\debloat.txt
```

В конце будет итог, например: `Отключено: 25. Нет на этом ТВ: 3. Не удалось: 0.` Строки `Unknown package` не страшны:
этого пакета просто нет на вашей прошивке.

Проверьте, что всё работает: откройте Настройки, переключите HDMI, запустите YouTube.

## Шаг 7. Настроить домашний экран

Откройте [launcher\res\values\config.xml](launcher/res/values/config.xml).

Посмотрите, какие приложения установлены:

```powershell
tools\venv\Scripts\python.exe -I tools\tv.py "pm list packages -3"
```

Впишите нужные в `dock_apps` в том порядке, в каком они должны стоять слева направо. Лучше всего выглядят 4–6 приложений. Те, что
не установлены, просто пропускаются, поэтому лишние строки ничему не мешают.

Заменить обои можно в `launcher\assets\wallpapers\`: файлы JPEG 1920×1080. Если опубликуете проект, укажите авторов в
`launcher\WALLPAPER-CREDITS.md`.

## Шаг 8. Собрать и установить

```powershell
launcher\build-and-install.ps1
```

Скрипт работает в безопасном порядке:

1. Собирает APK. Сборка идёт под Android 9, поэтому вызов более нового API сломал бы сборку, а не запуск на ТВ.
2. Делает резервную копию и определяет стандартный лаунчер.
3. Устанавливает APK и запускает новый лаунчер. **Стандартный домашний экран пока не тронут.** Если лаунчер упадёт, скрипт на этом остановится.
4. Отключает стандартный лаунчер и назначает новый на кнопку Home.
5. Проверяет, кому теперь принадлежит Home. Если не новому лаунчеру, сам возвращает стандартный.

В конце должно появиться: `Установлено. Нажмите Home на пульте.`

## Шаг 9. Проверка на пульте

Пройдите по списку. Главное здесь: Home изнутри приложения и работа после перезагрузки.

- [ ] **Home** открывает новый экран
- [ ] Открыть YouTube и нажать **Home**: вы вернулись на новый экран, а не остались в приложении
- [ ] Кнопка **вниз** открывает «Все приложения», **Back** возвращает к доку
- [ ] Кнопка **вверх** ведёт к **Входы**, **Wi-Fi**, **Настройки**, и каждая из них открывается
- [ ] **Входы** → HDMI: есть изображение и звук
- [ ] **Входы** → Эфирное ТВ: открывается ТВ (если пользуетесь антенной или кабелем)
- [ ] Кнопка **INPUT** на пульте показывает меню Sony
- [ ] Кнопка **Action Menu** работает
- [ ] Кнопка **Netflix** открывает Netflix (если он не отключён)
- [ ] Кнопка **Google Play** открывает Play Store
- [ ] Кнопка **микрофона** работает (если не отключена)
- [ ] Удержание **громкости** плавно меняет её
- [ ] **Перезагрузка**, после неё снова всё работает:

```powershell
tools\venv\Scripts\python.exe -I tools\tv.py reboot
```

Если что-то не работает, смотрите [раздел о проблемах](#если-что-то-пошло-не-так). Пункты, которые вы не проверили, стоит
иметь в виду, а не считать рабочими.

### Что ведёт себя иначе

- **Кнопка Apps**, если она есть на вашем пульте, может перестать работать. На KD-65A8F с той же прошивкой она не срабатывала после замены домашнего экрана: система отправляет её туда, где нет обработчика. Простого решения нет: используйте **Home**, затем **вниз**.
- **Включение ТВ:** телевизор может открыть последний вход или приложение, а не домашний экран. Просто нажмите Home.
- **Название Wi-Fi** на кнопке показывается, только если на ТВ включено определение местоположения. Без него будет просто «Wi-Fi». Если хотите видеть имя сети, включите его в **Настройки устройства → Местоположение**.
- **Процессы:** `com.sony.dtv.discovery` может продолжать работать в фоне, даже когда отключён. Экран рекламы он больше не показывает, но процесс может остаться.

## Шаг 10. Закрыть отладку

**Обязательно.** ADB по сети не шифруется, и пока он открыт, любое устройство в вашей сети может попытаться подключиться к ТВ.

На ТВ: **Настройки устройства → Для разработчиков → Отладка по USB → выключить**.

Лаунчер и все настройки сохранятся. Чтобы потом менять док или делать откат, включите отладку снова. Этот компьютер ТВ уже помнит.

## Откат

Вернуть всё как было (нужна включённая отладка):

```powershell
tools\restore.ps1 examples\sony-bravia-kd55xf9005\debloat.txt -DryRun
tools\restore.ps1 examples\sony-bravia-kd55xf9005\debloat.txt
```

Пакеты, которые были отключены ещё до вас, останутся отключёнными: скрипт смотрит самую старую копию в `backup\`.
Поэтому **не удаляйте папку `backup\`**.

Удалить сам лаунчер (не раньше, чем вернётся стандартный экран):

```powershell
tools\venv\Scripts\python.exe -I tools\tv.py "pm uninstall com.mihir.tvhome"
```

Вернуть только одно приложение:

```powershell
tools\venv\Scripts\python.exe -I tools\tv.py "pm enable com.google.android.katniss"
```

**Крайний случай:** **Настройки устройства → Сброс** возвращает ТВ в заводское состояние и отменяет всё сделанное
здесь. Вместе с этим удалятся ваши приложения и учётные записи. Обычно это не требуется.

## Если что-то пошло не так

### Подключение

| Что видите | Что делать |
|---|---|
| `Нет связи с ТВ` | ТВ включён, а не в режиме ожидания? Выключите и снова включите отладку на ТВ. Адрес мог смениться: запустите `tools\find-tv.ps1` |
| `ТВ не найден` | Отключите VPN на компьютере и проверьте, что ТВ не в гостевой сети. Задайте адрес вручную: `tools\find-tv.ps1 -Ip <адрес>` |
| `ТВ не разрешил подключение` | Вы не успели ответить на запрос на экране или ответили «Нет». Повторите команду и подтвердите |
| `отвечает не Sony` | Сохранён адрес другого телевизора. Посмотрите IP в сетевых настройках Sony и задайте его: `tools\find-tv.ps1 -Ip <адрес>` |
| Запрос на экране не появляется | Выйдите на домашний экран, выключите и включите отладку, повторите |

### Запуск скриптов

| Что видите | Что делать |
|---|---|
| `выполнение сценариев отключено` | Разрешите для этого окна: `Set-ExecutionPolicy -Scope Process Bypass` |
| `файл не имеет цифровой подписи` | Проект скачан архивом: `Get-ChildItem -Recurse *.ps1 \| Unblock-File` |
| `Перенесите проект в папку без пробелов и кириллицы` | Переместите его, например, в `D:\tv-home-bravia` |

### Установка лаунчера

| Что видите | Причина и решение |
|---|---|
| `INSTALL_FAILED_OLDER_SDK` | Android на ТВ старше 7. Обновите прошивку |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | Вы удалили `launcher\debug.keystore`. Удалите лаунчер с ТВ и установите снова: `tools\restore.ps1 ...`, затем `pm uninstall com.mihir.tvhome` |
| `INSTALL_FAILED_INSUFFICIENT_STORAGE` | Мало места: **Настройки устройства → Память**, удалите лишнее или очистите кэш |
| `Home сейчас принадлежит ...` | Домашний экран у ТВ необычный. На ТВ ничего не менялось. Укажите пакет лаунчера: `-StockLauncher <пакет>` |
| `Новый лаунчер упал` | Стандартный экран не тронут. Посмотрите причину: `tools\tv.py "logcat -d -b crash"` |

### После установки

| Что видите | Что делать |
|---|---|
| Home открывает старый экран | Проверьте владельца: `tools\tv.py "cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME"`. Запустите `launcher\build-and-install.ps1` снова |
| Home открывает экран настройки (`setupwraith`) | Только в этом случае отключите мастер: `tools\tv.py "pm disable-user --user 0 com.google.android.tungsten.setupwraith"`. **Может стереться сохранённый Wi-Fi**: заново подключите ТВ к сети с пульта. Откат: `pm enable` |
| Home показывает лаунчер позади приложения | `tools\tv.py "am force-stop com.android.tv.settings"`, затем перезагрузите ТВ |
| «Входы» не переключают HDMI | Используйте кнопку INPUT на пульте: она работает независимо от лаунчера. Список входов покажет `tools\tv.py "dumpsys tv_input"` |
| Новое приложение не появилось | Вернитесь на домашний экран. Если не помогло, перезагрузите ТВ |
| После обновления прошивки вернулась реклама | Обновление могло включить пакеты обратно. Повторите шаги 6 и 8 |

Здесь `tools\tv.py` для краткости означает `tools\venv\Scripts\python.exe -I tools\tv.py`.

### Скриншоты

```powershell
tools\venv\Scripts\python.exe -I tools\tv.py --shot screen.png
```

Чёрный снимок HDMI и эфира, а также пустой снимок настроек Sony это норма: эти слои защищены. Посмотреть такой экран
можно текстом: `tools\tv.py "uiautomator dump /dev/tty"`.

## Набор текста с клавиатуры компьютера

Откройте на ТВ поле ввода с экранной клавиатурой, затем:

```powershell
tools\type.ps1 "hello world"
tools\type.ps1
```

Второй вариант спрашивает текст скрыто, это удобно для паролей: текст не попадает в историю команд. Работает только с
латиницей, цифрами и знаками: кириллицу команда `input text` не вводит.
